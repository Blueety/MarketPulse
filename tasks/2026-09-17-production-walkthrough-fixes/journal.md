## 4. 遇到的问题（红跑/绿跑抓出来的，均已修）

### 4.1 PW-3b 运行时 colspan 断言恒红（断言写错）

`colspan="5"` 是**模板骨架行**的契约（P-4）；数据到达后骨架被真实行替换，**运行时 DOM 里根本没有**
`td[colspan]` ⇒ 运行时断言恒红。修法：改为对**模板源**的静态断言（`index.html` 源里 `colspan="5"` ≥2
+ 空表头标注在位）—— P-6b 同款手法。⚠️ 教训：**"骨架契约"类断言要对源码断，不对运行时 DOM 断**。

### 4.2 PW-4 的 empty 分支根本没测到（mock 复用 ok 夹具）

history mock 最初只有 ok 夹具，"empty 分支"点击刷新后返回的还是 ok 数据 ⇒ `emptyText` 保持 `""` ⇒ 断言红，
但红的原因是**测试没构造出 empty 态**。修法：mock 增加 `mode["empty"]` 开关 + `PW_HISTORY_EMPTY` 夹具。
⚠️ 教训：**分支类断言必须确认"真的进入了那个分支"**（看观测值，别只看断言结果）。

## 6. 补记（最终验证 + G1 措辞实测选型）

### 6.1 G1 措辞的实测选型（带日期的行会折行，撞既有滚动护栏）

首版按 plan 字面实现「告警日收盘（2026-09-11）：」，但全量跑暴露 `B-12a/b`（告警滚动组）**新增红**：

```
B-12a 1 条内容 → 周期 ≤ clientHeight（不足一屏）      actual=(2, 138, 132)
B-12b 内容不足一屏 → scrollTop 恒 0（不滚动/不抖动）   actual=[26, 28, 32, 35]
```

根因：新文案更长 ⇒ **单条告警卡 134px > 容器 132px** ⇒ 自动滚动被启动 ⇒ "原地抖动"
（正是 B-12 护栏要防的）。**这不是断言错，是文案放不下** ⇒ 用探针（`%TEMP%\mp_g1_fit.py`）
把 5 个措辞变体逐个注入 DOM 实测卡片高度：

| 变体 | 卡高 | 行高 | 判定 |
|---|---|---|---|
| V1 首版（全日期 + 告警前一日收盘） | 134 | 35（折行） | ✗ |
| **V2 选用：`告警日收盘：15.84 ｜ 前一日：17.84`** | **117** | **17** | **✓** |
| V3 半日期（09/13）+ 前一日 | 134 | 35 | ✗ |
| V4 半日期 + 短前一日 | 134 | 35 | ✗ |
| V0 原版（当前值 / 昨日收盘） | 117 | 17 | ✓（但无时间锚点） |

⇒ **日期不进这一行**（由卡片头部承载 —— plan 本就保留头部日期），行内只写「告警日收盘 / 前一日」。
`PW-1` 断言同步改为：行内出现「告警日收盘：」且无「当前值：」；新增 **PW-1b** 断言卡片头部仍含告警日期。
教训：**往"高度敏感"的滚动容器里加字，必须先实测卡片高度**（本项目已有 B-12 护栏，正好接住）。
