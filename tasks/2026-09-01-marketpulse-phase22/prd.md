# Task Handoff：MarketPulse 第二十二期 — 趋势图数据密度优化

> 复制到 `tasks/2026-09-01-marketpulse-phase22/prd.md`


## Goal

继续优化趋势图,重点解决**数据点过少、曲线过度平滑、图表空间利用率低**的问题。

## 核心方向

- 增加真实数据密度(使用完整交易日数据)
- 降低曲线人工平滑感
- 减少辅助元素
- 提高有效空间利用率

## Context Pointers

### 需修改的文件

| 文件 | 动作 | 说明 |
|------|------|------|
| `web/templates/index.html` | 修改 | 图表数据处理和配置 |
| `web/app.py` | 检查 | 确认后端数据完整性 |


## Constraints

- 不修改后端数据源和市场数据计算逻辑
- 不改变 7D / 30D / 90D 的业务行为
- 不新增不必要的依赖
- 不改变现有 2×2 趋势图布局
- 不通过虚构/插值/随机生成数据来增加数据点
- X 轴可以减少显示标签,但不能删除底层数据
- 不要为了让曲线更漂亮而改变真实数据走势
- 不要继续明显增加图表高度
- 保持现有涨跌颜色语义
- 保持 Tooltip 的数据准确性
- 保持响应式布局和宽屏兼容性


## Done When

- [ ] 30D 使用完整交易日数据,而不是只有约 6 个数据点
- [ ] 7D / 90D 同样保留完整时间序列
- [ ] X 轴只显示约 5-7 个日期标签,但底层曲线使用完整数据
- [ ] 曲线平滑程度明显降低
- [ ] 曲线走势自然反映真实数据变化
- [ ] 默认状态不显示所有数据点
- [ ] 最新数据点缩小到克制尺寸
- [ ] Hover 时有明确反馈
- [ ] 图表高度维持当前合理水平
- [ ] Legend 被合理弱化或移除重复信息
- [ ] 四张趋势图拥有统一规范
- [ ] 7D / 30D / 90D 切换后视觉表现一致
- [ ] 页面不会因数据点增加而出现性能问题
