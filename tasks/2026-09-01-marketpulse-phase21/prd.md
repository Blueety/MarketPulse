# Task Handoff：MarketPulse 第二十一期 — 趋势图视觉优化

> 复制到 `tasks/2026-09-01-marketpulse-phase21/prd.md`


## Goal

优化 MarketPulse 首页趋势图,解决当前图表明显"扁平、松散、像普通 Dashboard 图表"的问题,使趋势图更具金融终端的专业感。

## 核心方向

- 保留 2×2 布局
- 增加图表纵向空间(320-350px)
- 压缩非数据元素(标题/Legend)
- 减少过度平滑(轻微曲线)
- 减少常驻数据点(仅末端)
- 弱化辅助元素(网格/坐标轴)
- 强化数据走势本身

## Context Pointers

### 需修改的文件

| 文件 | 动作 | 说明 |
|------|------|------|
| `web/templates/index.html` | 修改 | 图表配置和布局 |
| `web/static/style.css` | 修改 | 图表容器样式 |


## Constraints

- 不修改后端数据获取和计算逻辑
- 不改变 7 / 30 / 90 天功能
- 不改变现有指标筛选逻辑
- 不新增无必要的依赖
- 保留当前 2×2 趋势图整体布局
- 不通过单纯增加颜色/阴影/渐变制造高级感
- 涨跌颜色保持现有语义
- 保持桌面端宽屏布局稳定


## Done When

- [ ] 每张趋势图纵向空间明显增加(320-350px)
- [ ] 曲线不再使用过度平滑效果
- [ ] 默认状态下不再显示大量数据点
- [ ] Hover 时清晰显示日期和数值
- [ ] X/Y 轴简洁、清晰
- [ ] 网格线进一步弱化
- [ ] Legend 不再与顶部指标重复
- [ ] 四张图统一视觉比例
- [ ] 页面保持专业、克制、现代
- [ ] 1440px 及更宽窗口不出现扁平
- [ ] 现有市场数据和切换功能正常
