# Task Handoff：MarketPulse 第二十三期 — 趋势图视觉精修

> 复制到 `tasks/2026-09-01-marketpulse-phase23/prd.md`


## Goal

对当前趋势图做最后一轮视觉精修,降低折线生硬感、改善 Chart Header 信息布局,降低多指标图表的视觉噪音。

## 核心方向

- 保留当前完整真实数据、2×2 布局和图表高度
- 降低折线锯齿感(轻微平滑,不是强 spline)
- 改善 Chart Header 信息布局
- 降低多指标图表的视觉噪音

## Context Pointers

### 需修改的文件

| 文件 | 动作 | 说明 |
|------|------|------|
| `web/templates/index.html` | 修改 | 图表配置和布局 |
| `web/static/style.css` | 修改 | 图表容器样式 |


## Constraints

- 只做精修,不进行趋势图重构
- 保留当前 2×2 布局
- 保留完整真实交易日数据
- 不修改后端数据
- 不改变 7D / 30D / 90D 的业务逻辑
- 不新增不必要的依赖
- 不使用渐变/发光/厚重阴影
- 不恢复强 smooth
- 真实数据的局部拐点必须保留
- 不通过修改 Y 轴范围夸大市场波动


## Done When

### 曲线质感
- [ ] 折线从锯齿感降低到自然的金融走势图质感
- [ ] 使用轻微平滑,不是强烈 spline
- [ ] 数据拐点仍然清晰可辨
- [ ] 四张图的曲线视觉语言保持一致
- [ ] 线宽保持克制(约 1.5-2px)
- [ ] 最新数据点保留但缩小

### Chart Header
- [ ] 左侧标题和右侧指标属于同一视觉层级
- [ ] 缩小两侧之间过大的无意义空白
- [ ] Header 内部垂直居中
- [ ] 指标信息仍使用对应曲线颜色

### 多指标视觉噪音
- [ ] 三条曲线仍然全部显示
- [ ] 降低非交互状态下的视觉攻击性
- [ ] 可通过适度降低线条不透明度/线宽/对比度实现
- [ ] Hover 或选中指标恢复完整视觉强调

### 整体视觉
- [ ] 四张图放在一起时视觉重量统一
- [ ] 不增加大量装饰元素
- [ ] 第一眼更接近"现代金融产品"
