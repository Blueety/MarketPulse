# Task Handoff：MarketPulse 第十二期 — 相关性分析

> 复制到 `tasks/2026-09-01-marketpulse-phase12/prd.md`


## Goal

在日报中增加相关性分析模块,计算主要指数之间的相关系数,帮助发现跨市场传导信号。

## 分析范围

| 指数对 | 解读意义 |
|--------|---------|
| VIX ↔ 标普500 | 负相关越强,美股对恐慌越敏感 |
| VIX ↔ 上证 | VIX对A股的传导强度 |
| 标普500 ↔ 上证 | 中美股市联动性 |
| 纳斯达克 ↔ 创业板 | 中美科技股同步性 |
| MOVE ↔ VIX | 债市恐慌是否传导到股市 |

## 输出

- 相关性矩阵表格(4-6组关键对)
- 颜色编码: >0.5红色, <-0.5绿色, 中间灰色
- 显著相关性(|r|>0.5)写入 context.json

## Constraints

- 数据窗口:最近30个交易日
- 至少10个有效数据点才能计算
- Pearson相关系数,纯Python实现(零新依赖)
- -1到1,保留两位小数
- **输入用收益率(每天涨跌幅%),不是原始价格**
