## 2. 实测证据

> 工具：Playwright；服务 `uvicorn --port 8025`；视口 1920×1080 / 1600 / 1280 / 375×812；两主题；console error **0**

### 2.1 D1 · 深色模式失效（真 bug）

```text
/macro   pref=dark  -> attr=light  bg=rgb(247,248,250)   ← ❌ 深色偏好被忽略
/        pref=dark  -> attr=dark   bg=rgb(11,15,20)      ← ✅ 首页正常
```

**根因**：`macro.html:2` 硬编码 `<html data-theme="light">`，内联脚本只处理"切到 light"：

```html
<!-- macro.html:10-18 -->
<script>
  (function () {
    try {
      if (localStorage.getItem("mp-theme") === "light") {          <!-- 只处理 light -->
        document.documentElement.setAttribute("data-theme", "light");
      }
    } catch (e) {}
  })();
</script>
```

存储为 `dark` 时**没有任何代码把 `dark` 写回**，属性停留在 HTML 里的 `light`。首页能work是因为 `app.js` 有主题初始化；`macro.js:108/137` 虽有 `getTheme/setTheme`，但**只在点击切换按钮时调用，未在 init 阶段应用**。

**影响**：用户首页切深色 → 点进宏观数据 → **页面突然变浅色**。直接违反 PRD 的 Done When「Dark / Light 均保持高级感」。

### 2.2 D2 · 宏观关系标注与行为不符

```text
标注: 1 年滚动窗口 · 相关系数 |r| ≥ 0.5 才列出
列出 6 行，|r| 最大值 = 0.47，达到 0.5 的 = 0     ← 不符
  原油 ↔ 10Y 美债  +0.47 正相关 · n=251
  美元 ↔ 10Y 美债  +0.38 正相关 · n=251
  美元 ↔ 黄金      -0.37 负相关 · n=251
  美元 ↔ 原油      +0.24 正相关 · n=251
  黄金 ↔ 10Y 美债  -0.18 负相关 · n=251
  黄金 ↔ 原油      -0.14 负相关 · n=251
```

**两个独立问题**：
1. **标注是错的** —— 要么过滤没实现，要么阈值不是 0.5。**必须校实**
2. **产品问题**：6 行里 3 行 |r| < 0.25 属于**弱相关**，展示价值低，却占了 293px（全页第 3 高模块）→ 正是 PRD 要解决的问题（「默认只突出最重要的 2~3 个关系」）

### 2.3 D3/D4 · 主图「全部对比」模式

```text

Y轴 ticks=[50, 100, 150, 200]                      ← D4：范围过大
  美元指数 first=100 last=102.1
  10Y美债  first=100 last=122.8
  原油     first=100 last=165.8
```

- **D3**：`borderWidth` 全等 → 无视觉主次（PRD 明确要求"选中序列权重最高，其他降低存在感"）
- **D4**：轴 50–200 而数据 100–165 → **上下各浪费约 50px**，有效起伏被压扁到中间 43%
- ✅ **归一化本身正确**（first 全为 100）

## 3. 设计方向

### 3.1 先修 bug，再做美化（顺序不能反）

D1（深色失效）与 D2（标注造假）是**正确性问题**，必须在视觉优化之前修 —— 否则改完样式，用户仍看到"首页深色、宏观页浅色"，且会以为"关系阈值就是 0.5"。

### 3.2 「降卡片感」的具体做法（对应 PRD R2，最大设计风险）

现状 7 张 `.mac-card`：**padding 20px、间距全等、边框全等、圆角全等** → 视觉权重完全相同。

**方向：分层 —— 不是减卡片数量，而是让它们不再"等权"。**

| 层级 | 模块 | 处理 |
|---|---|---|
| **一级** | 当前宏观环境 | **去掉卡片边框**，改为**无边框区块**（只有背景色差或仅一条细规线）→ 与下方卡片形成对比 |
| **二级** | 宏观市场（主图） | 保留卡片，但**加宽、加高**，成为唯一"重"的卡片 |
| **三级** | 核心变量 + 宏观因子 | 合并为**一个**卡片内的两栏（去掉 `mac-vars` / `mac-factors` 两层卡片壳） |
| **四级** | 宏观关系 + 历史环境 | 同三级，合并为一个卡片 |
| **五级** | 经济数据 | 保留卡片但**降低对比度**（更浅的背景 / 更弱的边框）|

→ 7 张卡 → **4 个视觉块**，且各有权重差异。

⚠️ **不要用"缩小 padding"来降卡片感** —— 那只是把卡片变小，结构还是卡片堆。

### 3.3 PRD 各要点的落地方式

| PRD 要点 | 落地 |
|---|---|
| 2 · 宏观环境三段式 | 左（Risk-On 大 + 中文解释）/ 中（Macro Score 独立焦点）/ 右（四维度方向）。**收紧中间空档**（现状左中右之间有大片空白）|
| 2 · 不增加仪表盘 | ✅ 保持纯排版，不加环形进度条 |
| 3 · 主图线条主次 | **选中序列 `borderWidth` 2.4 + 不透明；其他 1.2 + 低透明度**（D3）|
| 3 · Y 轴收紧 | 全部对比模式轴范围**按数据 min/max 加 8% padding**，而非写死 50–200（D4）|
| 3 · 网格弱化 | 沿用既有 token，降 alpha |
| 4 · 核心变量紧凑表 | 2×2 网格 → **4 行表格**（名称 / 数值 / 日变化 / **状态词**）。填掉 D6 的留白 |
| 5 · 因子加市场影响 | 每因子**加一行**「影响资产 + 受益/承压」→ **正好填掉 D5 的 77px** |
| 6 · 关系重点化 | 默认只显示 **\|r\| 最大的 2~3 条** + 「查看全部 →」展开（折叠其余）；**修正标注**（D2）|
| 7 · 历史突出当前 | 顶部加「**当前：Risk-On · 已持续 X 天**」，统计条降为次级 |
| 8 · 经济数据降权 | 保留 4 列，**降低卡片对比度**；`数据月份` 保留 |
| 9 · 空间优化 | 主要靠 §3.2 的分层 + D5/D6 的填充；**1280 档** 让 `.mac-2col` 保持 2 列（D10）|
| 10 · 视觉规范 | 低饱和、细边框、轻阴影；**禁止彩色卡片堆叠** |
| 11 · 响应式 | 1280/1920 重点；375 主图 **≥360px**（D11，现 325）|
