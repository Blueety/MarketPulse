# Task Handoff：MarketPulse 第十八期 — 板块聚合

> 复制到 `tasks/2026-09-01-marketpulse-phase18/prd.md`


## Goal

将175个概念板块聚合为10-15个大类板块,用成交额加权计算聚合涨跌幅。


## 板块映射表

| 大类 | 包含的概念板块 |
|------|--------------|
| **通信/电子** | 5G概念、华为概念、消费电子、物联网 |
| **光伏/新能源** | 光伏、光伏概念、新能源、锂矿、锂电池、盐湖提锂 |
| **半导体/芯片** | 芯片、半导体、集成电路 |
| **军工** | 国防军工、军工航天、军民融合 |
| **医药** | 创新药、仿制药、免疫治疗、CRO概念 |
| **消费** | 白酒、食品饮料、新零售 |
| **金融** | 券商、银行、保险 |
| **地产/基建** | 房地产、基建、水泥 |
| **资源/有色** | 黄金概念、有色金属、稀土、煤炭 |
| **农业** | 农业、养殖、猪肉 |


## 计算方式

```
聚合板块涨跌幅 = Σ(子板块涨跌×子板块成交额) / Σ(子板块成交额)
```

## Constraints

- 不修改概念板块数据获取逻辑
- 聚合后板块数量 ≤15 个
- 未匹配的概念板块归入"其他"
- 成交额为0时用简单平均
