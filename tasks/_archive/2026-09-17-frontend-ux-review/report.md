## 二、逐维度发现（现象 → 影响 → 建议）

### 1. 可发现性 ★★★★☆
- **现象**：侧栏 9 个可用项 + 2 个禁用项（`title="未开放"`）；顶栏搜索/通知/头像为禁用占位且带 `title="数据未接入"` + `aria-disabled`；跨页链接「宏观数据 / 中国宏观」位置合理。
- **影响**：正向。用户不会误点死链接。
- **建议**：`title` 在触屏端不可见，禁用占位建议补可见的角标或弱化样式（已有 `is-disabled`，保持即可）；P3。

### 2. 可理解性 ★★★★☆
- **现象**：全站标注数据时点与口径（`数据月份：2026年8月`、`同比 = 本期 vs 去年同月…箭头 = 同比较上期`、`Δ = 与 6 个月前相比（bp）`、地产卡注明「仅覆盖 2 城」）。这是同类看板里少见的认真。
- **问题**：①「全球市场动态」promo 与「资金流向（近5日）」为长期 `data-placeholder` 占位，只有「数据未接入」三个字，无接入计划/替代入口；②侧栏时钟 `.ms-time` 字号 **10px**（低于 11px 可读下限）。
- **建议**：占位块补一行「预计接入时间或对应后端任务」；`.ms-time` 提到 11–11.5px。P3 / P2(时钟字号随对比度一并修)。

### 3. 可操作性 ★★★★☆
- **实测**：趋势 4 类别 tab（美股大盘/A 股大盘/波动率/另类资产）点击即切、active 态正确；7D/30D/90D/1Y 范围切换标签联动（`近 7 日`→`近 1 年`）；板块 A股/美股双 tab 切换正常；主题按钮切换 + `localStorage` 持久化 + reload 后保持；侧栏锚点滚动生效（scrollY=247）。
- **亮点**：纯 CSS 双 tab 的 radio **没有 `display:none`**（绝对定位 + opacity:0），键盘点击与焦点都活着——很多产品在这里直接做坏。
- **建议**：无阻断项。

### 4. 反馈 ★★☆☆☆（主要短板）
- **现象**（`app.js:1063-1090`）：`refresh()` 无 loading 态、不禁用按钮、无 toast；`fetch().catch(() => renderMainChart())` **把失败静默吞掉**。全页 **0 个 `aria-live` / `role=status` / `role=alert`**。
- **影响**：点「刷新」后成功与失败在 UI 上**完全一样**；数据停在旧日期时用户无法区分「没新数据」还是「取数挂了」；屏幕阅读器完全感知不到数据更新。
- **建议**：①刷新期间按钮转圈/禁用；②失败时在趋势卡顶部用现成的 `#chart-main-empty` 通道提示并提供重试；③给顶栏日期/趋势卡补一个 `aria-live="polite"`。P1。

### 5. 状态覆盖 ★★★★★
- **实测**：骨架屏（`.sk-row/.sk-card/.sk-item`，加载完成后 0 残留）、空态（`暂无数据`）、失败条（`#mac-fail-bar` + **重试按钮**）、禁用占位四态齐全；宏观页 `as_of`/口径脚注在失败时也有兜底文案（`数据暂缺`）。
- **风险提示（非 UI 缺陷）**：当前上游数据源大面积不可用（Yahoo 403 / BLS），看板多数时间运行在降级态。降级态做得多好，就越容易**掩盖前端回归**——验收务必用基线 A/B 判定，不要只看「红条数」。
- **建议**：保持；把「降级态下的验收基线」写进 `verify_ui.py` 文档。

### 6. 容错 ★★★☆☆
- **现象**：宏观页失败 → 失败条 + 重试；**首页同场景 → 静默**（见维度 4）。CDN 降级倒是做了：Chart.js 加载失败时 `canvas` 隐藏并显示「图表加载失败（离线 / CDN 不可达）」（`app.js:710-717`）。
- **建议**：把宏观页的「失败条 + 重试」模式下沉为共享组件，首页复用。P2。

### 7. 一致性 ★★★☆☆
- **现象 ①（主题初始化分叉）**：`index.html:11-17` 的内联脚本**只处理 `light`**（老写法）；`macro.html`/`macro_cn.html` 已按 D1 修复为 light/dark 双处理。首页 `app.js:16` 虽会在 body 末尾 `applyTheme(getTheme())` 兜底，但深色用户每次进首页都有一瞬**浅色闪变（FOUC）**，且三页初始化策略不再一致——正是 `macro.html` 注释里警告过的「改一处必须改三处」。
- **现象 ②（大纲）**：首页 `h1=0`（卡片直接从 h2 开始）；宏观页 `main` 内 `.mac-head` 又是 `<header>`，导致页面出现 2 个 header landmark。
- **建议**：①把 macro 版内联脚本同步回 `index.html`（三处同改 + 互指注释）；②首页 `#lede` 上方补视觉隐藏的 h1；`.mac-head` 改 `<div>`。P2 / P3。

### 8. 性能与可访问性 ★★★☆☆
- **对比度（浅色主题，实测 WCAG 4.5:1 口径）**：
  - `--text-tertiary`（#9CA3AF）在页面底色上 **2.39**、白卡上 **2.54**，且大量**承载信息**：北京时间(10px)、宏观口径脚注(11px)、单位「亿元」、`正相关 · n=251`、`VIX 平静 / MOVE 平静`、`数据未接入`(2.26)、禁用 `查看全部 →`(2.49)。
  - 图表 meta 涨跌色 rgb(19,194,194) 白底 **2.19**（12px/600）；相关性 pill.pos 3.21。
  - **深色主题仅 2 处轻微不足**（白字 on #3B82F6 = 3.68），明显更健康。
  - ⚠️ 探针误报已剔除：promo 卡「白字 1.06」——实际背景是不透明渐变 `#1D4ED8→#0EA5E9→#14B8A6`，真实对比度达标（探针只读了 `backgroundColor`）。
- **建议**：浅色主题把 `--text-tertiary` 加深一档（如 #6B7280 ≈ 4.6:1），涉及 `.ms-time/.mac-note/.f-note/.v-unit/.rel-n/.ph-note/.link-btn` 及图表 meta 涨跌色同步加深。P1。
- **其他实测通过项**：37/37 可聚焦元素**全部有可见焦点环**；无图片缺 alt；`lang=zh-CN` 正确；4 视口（含 769 断点带）**0 真实横向溢出**；0 console 错误、0 失败请求；`prefers-reduced-motion` 下 Chart.js 动画关闭、backdrop-filter 有降级。
- **移动端抽屉**：遮罩（`.nav-backdrop`）存在且点击可关，但 **body 无滚动锁定**、**焦点不移入抽屉**——抽屉开着时背景仍可滚动。P2。

## 三、体验总结：整体印象与核心风险

**整体印象**：这是一个**工程自觉明显高于平均水平**的内部看板。状态覆盖（骨架/空/失败/禁用四态）、数据口径与时点标注、纯 CSS tab 的键盘可达性、CDN 失败的显式降级、多视口零溢出——这些通常是「上线后被投诉才补」的东西，这里提前做掉了。

**核心风险两条线**：
1. **反馈链路（P1）**：刷新零反馈 + 失败静默 + 无 aria-live。在看板类产品里，「数据新不新」是第一信任问题；当前用户无法区分「没新数据」和「取数挂了」。
2. **浅色主题可读性（P1）**：`--text-tertiary` 一档灰被同时用于口径脚注、单位、时点、涨跌注释等信息性文本，对比度 2.2–2.5 系统性低于 4.5。深色主题没有这个问题，说明 token 层有能力修，只差浅色侧的一档取值。

**环境性提示**：上游数据源（Yahoo/BLS）长期不可用使看板常驻降级态——UI 处理得当，但会掩盖前端回归，验收必须基线 A/B，不能只看绝对红条数。

## 五、亮点肯定

1. **状态覆盖满分**：骨架屏/空态/失败条+重试/禁用占位四态俱全，且骨架数量与真实内容同量级（防 CLS 的注释都写了）。
2. **口径标注文化**：每个数据块带「数据月份 + 计算口径」脚注，连「+21.20% 配 ↓ 箭头像 bug」这种歧义都提前用文案消解——这是对用户真正的尊重。
3. **键盘与焦点**：37/37 焦点环可见；纯 CSS 双 tab 不牺牲可达性（radio 绝对定位而非 display:none，注释里连原因都写清了）。
4. **降级诚实**：CDN 失败显示明确原因（「离线 / CDN 不可达」），禁用功能明说「数据未接入」，不装假交互。
5. **响应式扎实**：1500/1024/769/390 四视口零横向溢出，769 断点带无坏带。
6. **性能意识**：`prefers-reduced-motion` 全链路适配、backdrop-filter 降级、图表复用单实例不发重复请求（状态驱动）。
7. **深色主题对比度**：全页仅 2 处轻微不足，整体健康。
