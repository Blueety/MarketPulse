# Task Handoff：MarketPulse 第十七期 — Web 看板交互增强

> 复制到 `tasks/2026-09-01-marketpulse-phase17/prd.md`


## Goal

**增强 Web 看板的交互能力，让用户从"被动接收信息"升级为"主动探索数据"**。

当前看板静态展示最近 7 天数据，用户无法调整时间范围、筛选指标或排序表格。本次优化后，看板将支持时间范围切换、指标筛选、数据排序等核心交互，提升日常数据探索效率。


## Current Understanding

### 当前看板状态

- 技术栈：FastAPI + Chart.js + 原生 HTML/CSS/JS
- 数据来源：`/api/history` 返回全部历史数据，前端固定显示最近 7 天
- 图表：显示全部 7 个指数（VIX/VXN/MOVE/标普/纳指/上证/深证）的趋势线
- 表格：显示最近一天的数据，无排序功能

### 目标增强功能

| 功能 | 说明 | 优先级 |
| :--- | :--- | :--- |
| **时间范围选择器** | 切换 7天/30天/90天，图表和表格联动更新 | 高 |
| **指标筛选** | 勾选/取消勾选指数，图表只显示选中的曲线 | 高 |
| **图表交互优化** | 悬停显示数据点详情，支持缩放/平移 | 中 |
| **数据表格排序** | 点击表头按数值/涨跌幅排序 | 中 |
| **数据更新提示** | 页面顶部显示最后数据更新时间 | 低 |

## Constraints

- **保持轻量**：不引入新框架，继续使用 Chart.js + 原生 JS
- **响应式**：新增 UI 组件需适配移动端
- **性能**：切换时间范围时，图表重绘时间 ≤ 1 秒
- **向后兼容**：API 不改动现有调用方式，新增参数为可选
- **数据准确**：表格排序和图表数据保持同步


## Out of Scope

- 数据导出（CSV/Excel）
- 多图联动对比
- 自定义指标组合保存
- 实时数据推送（WebSocket）
- 用户账户/配置保存

## Risks

| 风险 | 应对 |
| :--- | :--- |
| 90天数据量大时图表渲染变慢 | Chart.js 对百级数据点渲染效率足够 |
| 指标筛选后表格和图表不同步 | 筛选逻辑统一由单一函数处理 |
| 时间范围切换导致页面刷新 | 使用 fetch 异步请求，只更新图表和表格 |
| 移动端图表悬停体验不佳 | Chart.js 原生支持 interaction.mode: 'index' |
