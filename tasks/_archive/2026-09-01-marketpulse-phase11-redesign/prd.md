# Task Handoff：Web 看板 UI 重新设计

> 复制到 `tasks/2026-09-01-marketpulse-phase11-redesign/prd.md`


## Goal

从"用户3秒内知道涨跌"出发,重新设计 Web 看板的图表和布局。

## P0 必须改

1. **7日图改成相对涨跌** — 每个品种第一天=100,显示相对变化
2. **去掉面积渐变填充** — 纯线条更干净
3. **标题旁显示7D涨跌幅** — 如"美股大盘 +2.41%"
4. **Y轴弱化** — 只显示百分比变化,不显示绝对价格
5. **X轴缩短** — 只显示日期数字(24/25/26...),不显示年月
6. **数据点弱化** — 不显示圆点,只保留最后一个点
7. **网格线弱化** — 半透明,不抢视线

## P1 强烈建议

8. **另类资产改成横向条形图** — 7D表现对比(BTC vs 黄金)
9. **波动率独立处理** — 基准化后显示,不和普通指数混
10. **Tooltip缩小** — 轻量浮层,宽度150-170px
11. **图例简化** — 标题下方小字,不占一行

## P2 最后调

12. 卡片padding 20px
13. 字体层级
14. 边框亮度
15. 圆角
16. 整体间距

## 技术实现

- Chart.js 配置: `type: "line"`, `fill: false`, `pointRadius: 0`, `pointHitRadius: 10`
- 数据处理: 后端 `/api/history` 返回时计算相对涨跌(基准100)
- 另类资产: Chart.js `type: "bar"` 横向条形图
- 波动率: 基准化后显示(每条线独立基准)

## Constraints

- 只改 web/ 目录(index.html + style.css + app.py)
- 不改 daily_report.py/src/*
- Chart.js CDN 不变
