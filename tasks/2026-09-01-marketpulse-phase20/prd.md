# Task Handoff：MarketPulse 第二十期 — Web 看板视觉升级

> 复制到 `tasks/2026-09-01-marketpulse-phase20/prd.md`


## Goal

将 MarketPulse 首页从"普通 SaaS / Admin Dashboard"视觉升级为**现代、专业、紧凑的金融市场终端**。

## 核心原则

- 数据优先、数字优先
- 图表与数据一体化
- 减少不必要的卡片边界
- 提高有效信息密度
- 保持视觉克制

## 目标风格

- Bloomberg / TradingView 的信息密度与数据感
- Apple 风格的克制、精致和层级
- 简洁、专业、低噪声

## Context Pointers

### 需修改的文件

| 文件 | 动作 | 说明 |
|------|------|------|
| `web/templates/index.html` | 修改 | 信息架构和布局调整 |
| `web/static/style.css` | 修改 | 视觉系统升级 |

## Constraints

- 不改变现有核心业务功能和数据获取逻辑
- 不删除已有市场指标、趋势图、热点板块和告警等核心信息
- 优先通过现有技术栈完成改造
- 涨跌颜色必须保持明确、统一、可读
- 核心数字必须成为页面最重要的视觉元素之一
- 保持响应式布局
- 保证现有 Railway 部署方式兼容


## Done When

- [ ] 首页第一眼不再像普通 Admin / SaaS Dashboard
- [ ] 核心市场指数和数字拥有明显且合理的视觉优先级
- [ ] 页面整体信息密度更加紧凑
- [ ] 减少不必要的 Card 边界和重复容器
- [ ] 图表与对应指标形成统一的信息模块
- [ ] 页面留白得到重新控制
- [ ] 涨跌、市场状态、告警等状态信息具有明确但克制的颜色体系
- [ ] 字体大小、字重、数字字体形成清晰层级
- [ ] 不出现横向滚动条、内容溢出
- [ ] 现有数据仍然正常加载和展示
