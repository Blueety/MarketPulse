# Task Handoff：MarketPulse 第十九期 — Web 看板混合筛选模式

> 复制到 `tasks/2026-09-01-marketpulse-phase19/prd.md`


## Goal

**为 Web 看板增加混合筛选交互**：顶部全局筛选器（按类别批量控制）+ 各图表独立图例点击（精细微调），两者状态双向同步。


## Current Understanding

### 看板现状

- 四个图表按类别划分：美股大盘、A股大盘、波动率、另类资产
- 每个图表包含该类别下的 2-4 个指标
- 图表使用 Chart.js 渲染，图例默认显示
- 顶部已有指标标签行和全选/清空按钮


### 目标增强功能

| 功能 | 说明 |
|------|------|
| **类别批量切换** | 点击"美股大盘"/"A股大盘"/"波动率"/"另类"按钮，仅显示该类别指标 |
| **全选/清空** | 一键显示全部/隐藏全部指标 |
| **图例点击** | 点击图表图例，仅在该图表内显隐指标 |
| **双向同步** | 顶部筛选与图例点击状态互相同步 |


## Context Pointers

### 需修改的文件

| 文件 | 动作 | 说明 |
|------|------|------|
| `web/templates/index.html` | 修改 | 调整筛选区 HTML + 新增批量按钮 + 图例点击逻辑 |
| `web/static/style.css` | 修改 | 新增批量筛选按钮样式 |


## Constraints

- **状态共享**：四个图表共享同一个 `selectedSymbols` 数据源
- **双向绑定**：顶部点击标签 → 图表更新；图表点击图例 → 顶部标签状态同步
- **保持图表类型**：不改变四个图表的分类结构
- **响应式**：新增筛选按钮适配移动端
- **性能**：使用 Chart.js `update()` 而非 `destroy()` 重建


## Out of Scope

- 跨图表拖拽指标
- 自定义图表布局
- 筛选状态持久化
