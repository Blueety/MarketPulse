# Task Handoff：A股北向资金监控

> 复制到 `tasks/2026-09-01-northbound-flow/prd.md`


## Goal

**为 MarketPulse 增加 A 股北向资金（沪深港通）监控能力**，在每日日报中展示当日北向资金净流入/流出数据，并在异常流入（如单日净流入超 100 亿）时触发独立告警。

北向资金被视为 A 股市场的"聪明钱"，其流向能反映外资对 A 股的态度，是判断市场情绪的重要参考指标。


## Current Understanding

### 政策背景与数据源现状

⚠ **关键前提**：自 2024 年 8 月起，沪深港通北向资金每日净流入明细**不再实时公开披露**。

这意味着：
- 传统 AkShare 接口（`stock_hsgt_hist_em`）返回的数据可能全为 0 或空值
- 需要采用**多源降级策略**来获取数据

### 数据源降级链（按优先级）

| 优先级 | 数据源 | 说明 | 可用性 |
| :--- | :--- | :--- | :--- |
| 1 | **adata** | 专注 A 股的免费量化库，支持实时北向资金 | ✅ 可用，无需 API Key |
| 2 | **cn-funds-mcp** | MCP 服务，提供沪深港通资金流向 | ✅ MCP 协议接入 |
| 3 | **akshare-stock-mcp** | MCP Server，含 `get_northbound_flow` 工具 | ✅ MCP 协议接入 |
| 4 | **Tushare Pro** | 需 3000 积分，有门槛 | ⚠ 备选 |
| 5 | **所有源失败** | 报告中标注"数据暂缺（接口限制）" | 不中断流程 |

### 数据字段

| 字段 | 说明 | 单位 |
| :--- | :--- | :--- |
| `net_inflow` | 北向资金当日净流入合计 | 亿元（人民币） |
| `sh_net` | 沪股通当日净流入 | 亿元（人民币） |
| `sz_net` | 深股通当日净流入 | 亿元（人民币） |
| `date` | 数据日期 | YYYY-MM-DD |

## Constraints

- **容错第一**：北向资金数据获取失败时，报告中显示"数据暂缺"，**不中断日报生成**
- **无需 API Key**：优先使用 `adata`（免费，无需注册）
- **定时调度**：在 A 股收盘后（北京时间 15:00-15:30）获取数据，与 A 股收盘快照同步
- **告警独立**：北向资金告警与现有 VIX/大盘告警分开记录和推送
- **测试覆盖**：新增代码需包含单元测试，覆盖成功和失败场景


## Out of Scope

- 分钟级北向资金实时监控（仅日度）
- 北向资金个股明细（仅合计数据）
- 历史北向资金趋势图（本次不扩展）
- 北向资金与指数相关性分析（后续可加）
- 南向资金监控（仅北向）

## Risks

| 风险 | 应对 |
| :--- | :--- |
| adata 因政策变化无法获取北向资金 | 已设计多级降级链；最终降级到"数据暂缺"状态，不影响其他模块 |
| 北向资金数据延迟（盘后较晚更新） | 调度时间设在 15:30 后，留出数据发布缓冲时间 |
| 告警阈值 100 亿过于敏感或不敏感 | 支持环境变量覆盖，用户可自行调整 |
| adata 依赖包较大 | adata 约 20-30MB，可接受；若觉臃肿可仅使用 MCP 服务 |
| 北向资金数据为 0（节假日/休市） | 判断当日是否为交易日，若休市则跳过获取，报告显示"休市" |
