# MarketPulse 使用指南

> 面向使用者（不是开发者）。看完这份，你应该能回答："这一屏数字在说什么、我该看哪个、看到这个我该做什么"。
>
> 开发/架构细节在 `architecture.md`；接口契约在 `system-overview.md`。

---

## 0. 先搞清楚这网站是干什么的

它不是行情终端（不能下单、不能实时逐笔）。它是**一个每天自动跑几次的"体检报告生成器"**：

```
自动取数  →  算异动/打分  →  出日报 + 告警  →  推 QQ（Hermes）
                                  └→  写进这个网页（只读镜像）
```

所以它回答的是三个问题：

| 问题 | 看哪里 |
|---|---|
| 今天市场发生了什么异常？ | **告警记录**（首页右下） |
| 现在整体环境是偏多还是偏空？ | **宏观页的 Macro Score** |
| 我关心的那几只 ETF 怎么样了？ | **自选列表** |

**数据多久更新**：每天 4 次自动跑（A股午盘 11:30 / A股收盘 15:00 / 美股开盘 21:30 / 美股午盘 00:00），每次都会重写页面读的数据。所以你早上看到的是昨夜美股收盘的数据——**不是实时的，也不需要实时**。

## 1. 看之前先记住三件事

这三条能消掉 90% 的"这数是不是错了"。

### ① 每个数字都有"数据日"，别拿两个日期的数对比

页面顶栏右上角那个日期（如 `2026-09-17`）是**数据日**，不是今天。告警卡上也有自己的日期。

> 真实案例：告警卡写 "VIX 当前值 15.84"，页面顶部写 17.71，看着像 bug。
> 其实前者是 **9-11 收盘**那天的告警快照（那天 VIX 从 17.84 跌到 15.84，触发了异动），后者是 **9-16 最新收盘**。告警是**历史档案**——每条冻结在"事发当时"，不会跟着市场更新。

所以：**告警里的数字是"那天的"，顶部数字是"最新的"，两者不矛盾。**

### ② 颜色有两套语义，别搞混

| 场景 | 红 | 绿 |
|---|---|---|
| **涨跌幅**（几乎所有地方） | 涨 / 正 | 跌 / 负 |
| **相关性 / 因子影响资产** | **正相关（同向联动）** | **负相关（对冲）** |

第二条容易反直觉：相关性表里 `美元 ↔ 黄金 -0.31` 显示绿色，意思是"这俩**反向**走"——它跟涨跌无关，只描述"两个东西是同进同退还是对着干"。

### ③ "看到"—" 不代表坏了

页面上的空状态有四种，含义完全不同：

| 显示 | 含义 | 要不要管 |
|---|---|---|
| 灰色闪动条（骨架屏） | **正在加载**，几秒后消失 | 不用管 |
| 「数据暂缺」 | 数据源**这次没取到**（网络/上游故障） | 点「重试」；反复出现说明上游有问题 |
| 「数据未接入」 | 这个模块**从来就没有数据源**，是**有意留的占位** | 不用管，也不用等 |
| 数字位一个「—」 | 该字段算不出来（如样本不足） | 看旁边的说明文字 |

⚠️ 特别提醒：**"全球市场动态"卡和"资金流向"块属于第 3 类**——它们是静态占位，不是坏的，不用去找数据源。

## 2. 首页（`/`）：30 秒扫读顺序

推荐顺序：**顶栏日期 → 4 张 KPI 卡 → 告警记录 → 自选列表 →（有时间再看别的）**。

### 2.1 顶部 4 张 KPI 卡

| 卡片 | 数字含义 | 用法 |
|---|---|---|
| 美股 · 标普500 | 最新收盘 + 涨跌幅 | 全球风险资产的"温度计" |
| A股 · 上证指数 | 同上 | 本地市场 |
| **VIX 恐慌指数** | 市场恐慌程度 | **低于 20 = 平静；20~30 = 警惕；≥30 = 恐慌**。这是最该天天看的一个数 |
| 自选 | 你自选列表里第一只 | 快速瞄一眼 |

每张卡右下角的小折线（sparkline）是**近 30 日走势的缩略图**，只表达形状（最近在爬还是在掉），不是精确读数。折线颜色 = 今日涨跌色。

### 2.2 市场趋势

- 四个 **类别 tab**：美股大盘 / A股大盘 / 波动率（VIX·VXN·MOVE）/ 另类资产（BTC·黄金）
- 四个 **时间范围**：7D / 30D / 90D / 1Y
- **用法**：切换 tab 不会重新联网取数（数据已在本地），所以随便点、随便看。鼠标移到图上会出一条水平参考线，方便比价。
- 「MOVE」是**债市版 VIX**（美债期权波动率）；「VXN」是纳斯达克的 VIX。三者都涨 = 全市场都在紧张。

### 2.3 自选列表

- **按涨跌幅从大到小排**，最美的放最上面，垫底的就是今天最差的
- 「最新价」是收盘价；右侧的**小横条**是涨跌幅的相对长度（今天涨得最猛的那条最长，用来横向比"谁更猛"）
- 每行的颜色方块是**标的标识**（一个标的固定一个颜色，不会随排序变化），里面的字是品类简称：酒=白酒、通=通信、光=光伏、房=房地产、电=消费电子、软=软件、港=恒生科技、半/芯=半导体
- 标题后的 `09-17 15:00` 是**快照时间**：说明这个数字是什么时候的
- ⚠️ 某只 ETF 显示「数据暂缺」= 那一只单独取数失败，其它行不受影响

### 2.4 告警记录 ← **最该重视的一栏**

只有**当日变化超过阈值**的标的才会出现在这里。每条卡片的构成：

```
[WARN]  VIX · 2026-09-11              ← 级别 + 标的 + 告警日
类型：close ｜ 市场状态：平静          ← 触发的场景 + 当时 VIX 所处区间
告警日收盘：15.84 ｜ 前一日：17.84 ｜ 变化率：-11.21%（阈值 ±8.4%）
建议：波动率仍处低位，建议保持现有策略，关注后续变化。
相关报告：2026-09-11.md
```

| 字段 | 什么意思 |
|---|---|
| **WARN / ALERT** | WARN = 波动异动；ALERT = 波动率同时处于**恐慌区间**（更严重一档） |
| 类型 | `close` = 收盘日报触发；`a-share-open` / `us-noon` 等 = 盘中快照触发 |
| 变化率 vs 阈值 | 「超过阈值」才会上榜，等于不算 |
| **阈值为什么每天不一样？** | 因为它是**动态的**：近 20 个交易日波动率均值 + 2 倍标准差。市场平稳时阈值自动收紧（±7% 也算异动），市场本来就狂野时阈值自动放宽。**这不是 bug** |
| 建议 | 按当时状态给的一句话（平静/警惕/恐慌三档），固定话术，不是投资建议 |

**这张卡会自动缓慢上滚**，是循环播放，鼠标移上去会停——不用追着看。

### 2.5 市场概览（6 小卡）

美股标普500、上证、黄金COMEX、美元指数、10Y美债、原油的"一眼版"。和 KPI 卡的差别：这里品种更全，KPI 卡只放最重要的 3 个 + 自选。

10Y 美债的 `%` 是**收益率**（如 4.05%），它涨 = 借钱变贵 = 通常对股市不利。

### 2.6 市场情绪 & 资金流向

- **风险偏好**：把 VIX 水平、MOVE 水平、VIX 五日变化三项合成一个档（风险偏好高 / 中性 / 低）。它会列出**参与打分的因子**（`VIX 15.8 · 平静`、`VIX 5日 -8.2%`），所以你能看到结论是怎么来的。**用途：一眼知道"现在是该进攻还是该防守"的气氛。**
- **资金流向**：**未接入**（有意占位，无数据源）
- **市场关系**：近 30 日里"明显同涨同跌"的指数对（相关系数 |r| ≥ 0.5）。
  - `+0.72` 红色 = 强同向（一个涨另一个大概率也涨）
  - `-0.68` 绿色 = 强反向（对冲关系）
  - 显示「未发现明显联动关系」= 这 30 天各走各的，**这是有效信息，不是空卡**
  - 鼠标悬停有解释

### 2.7 行业板块表现

A股 / 美股两个 tab（点标签切换），各列 **涨得最猛的 5 个板块**：板块名、涨跌幅、成交额、领涨股。

- ⚠️ 只列**领涨**，不列领跌（想看跌的请看日报）
- 标题旁若出现「数据截至 09-16」，说明这块数据比页面的数据日旧一天（A股/美股分别独立取数，可能不同日期）

### 2.8 最新资讯

自动抓取的财经新闻标题 + 一句话摘要（截断显示，可横向滚动）。**用途：知道今天市场在议论什么**，不保证每条都跟你的持仓相关。

和告警卡一样会**自动缓慢上滚**（鼠标移上去 / 键盘聚焦 / 切到别的标签页都会暂停），所以停下来的位置不代表"最新的只有这几条"——它是个循环播放列表。

## 3. 宏观页（`/macro`）：最像"考试"的一页，逐项拆解

这一页的目标只有一个：**回答"现在的大环境，是顺风还是逆风"**。

### 3.1 当前宏观环境（第一个大块）

#### ① 大字：`Risk-On 风险偏好上行` / `Neutral 中性` / `Risk-Off 风险规避`

三个状态，就这么简单。**它由下面的 Macro Score 决定**：Score > 62.5 → Risk-On；Score < 37.5 → Risk-Off；中间 → 中性。

- **Risk-On** = 市场愿意冒险（钱流向股票、商品，避险资产被冷落）
- **Risk-Off** = 市场想避险（钱流向黄金、美债、美元）
- **Neutral** = 没有明确方向

#### ② 四象限：`再通胀 / 复苏 / 滞胀 / 通缩衰退`

这是**宏观经济学最经典的一张图**：横轴看通胀（上行/回落），纵轴看增长（扩张/收缩），两两组合出四个格子。

| 象限 | 组合 | 通俗意思 | 历史上谁受益 |
|---|---|---|---|
| **复苏** | 增长↑ + 通胀↓ | 经济好、物价稳 ← **最舒服的环境** | 股票（尤其成长股） |
| **再通胀** | 增长↑ + 通胀↑ | 经济好但物价在涨 | 商品、能源、银行 |
| **滞胀** | 增长↓ + 通胀↑ | 经济差、物价还涨 ← **最难受** | 黄金、现金 |
| **通缩衰退** | 增长↓ + 通胀↓ | 经济差、物价也跌 | 债券 |

⚠️ 这里的"增长"用的是**就业数据替代**（不是 GDP），"通胀"用 CPI，旁边的 `口径：...` 一行会写明——**别看结论不看口径**。

#### ③ 大数字：**Macro Score（0~100）** ← 你最可能看不懂的那个

先说结论：**50 是中性，>62.5 偏乐观，<37.5 偏悲观。就当一个"温度计"读。**

它是怎么算出来的（四个维度，每项 -2 ~ +2，加总 -8 ~ +8）：

| 维度 | 看什么 | 高分（正）意味着 | 低分（负）意味着 |
|---|---|---|---|
| **风险偏好** | VIX + MOVE 所处区间 | 波动率低、市场平静 | 恐慌 |
| **美元** | 美元指数相对 50 日均线偏离 | 美元走弱 → 利好风险资产 | 美元走强 → 抽走流动性 |
| **利率** | 10Y 美债收益率的 5 日变化 | 收益率下行 → 借钱变便宜 | 收益率上行 → 压制估值 |
| **商品** | 原油 5 日变化 | 油价涨 → 需求/再通胀 | 油价跌 → 需求收缩 |

然后把 -8~+8 除以 8 归一化成 -1~+1，再映射成 0~100（所以 **50 恰好等于"四项全打 0 分"**）。

**⚠️ 三个必须知道的事**：

1. **它不是行业标准指标**，是这台机器自己定的四指标法（形态参考业界做法，信用利差那一路因为取不到数据换成了"波动率/美元/利率/商品"）。页面底部的「评分口径」一行会如实写出来——**别当成权威评级用**。
2. **缺数据的维度不计分，但分母仍然是 8** → 结果会自动偏向中性。这是刻意的保守设计（不猜）。
3. **它就是上面那个 Risk-On/Neutral/Risk-Off 大字的分值版**，两者同源，不会互相矛盾。

#### ④ 右侧四行：宏观因子（每行三个数）

```
风险偏好   0     VIX 平静 / MOVE 警惕
美元      -1     -1.20%    相对 50 日均线偏离
利率      -2     +0.28pp   10Y 5 日变化（百分点）
商品      +1     +3.40%    原油 5 日变化
```

- **中间那个带正负号的数（-2 ~ +2）= 该维度的得分**，红/绿表示正/负
- **右边的百分比/pp = 原始数据**，得分就是从它算出来的（比如美元偏离均线 -1.2% 落在 1~2% 档 → -1 分）
- `pp` = 百分点（percentage point），专门用于利率这种**本身已经是百分比**的指标，避免"4.00%→4.30% 算成涨 7.5%"这种量纲错误
- **最右边的「影响资产」**：把得分翻译成"哪些资产受益/承压"。⚠️ 这是**前端固定话术表**，不是模型预测——它只是说"按教科书，这种情况下通常谁受益"。

### 3.2 宏观市场（主图）

美元指数 / 10Y 美债 / 原油 / 黄金四选一，配 1M / 3M / 1Y / 5Y 时间范围。

- 10Y 美债有个量级保护：如果上游给来的原始值量级异常（绝对值 > 20，说明它按 "4.05 的 10 倍" 这种口径返回），图表会自动 **÷10** 换算后显示，并在 console 留一条提示。**所以你看到的是 4.05% 这种正常量级，不会是 40.5**
- 下方那行 `foot` 是数据条数与窗口说明

### 3.3 核心宏观变量

四行紧凑表，每行：**名称 / 数值 / 日变化% / 状态词**。

状态词是把日变化说成人话（**不是观点、不是预测**）：

| 日变化 | 状态词 |
|---|---|
| ≥ +1% | 明显走强 |
| +0.2% ~ +1% | 小幅走强 |
| -0.2% ~ +0.2% | 基本持平 |
| -1% ~ -0.2% | 小幅走弱 |
| ≤ -1% | 明显走弱 |

分档阈值是工程取值（就是个方便阅读的刻度），不代表"涨 1% 一定有含义"。

### 3.4 宏观关系

**1 年**滚动窗口的六对品种相关性（美元↔黄金、美元↔原油、美元↔10Y、黄金↔原油、黄金↔10Y、原油↔10Y）。

- 优先列 **|r| ≥ 0.5 的显著对**（最多 3 组）；一对都没有时，**列出最强的 2 组并在标注里明说"当前无显著对"**——它绝不把弱相关伪装成显著
- `样本不足` = 有效数据点不够 30 个，算不出可信的 r（**显示"样本不足"而不是显示 0**，因为 0 会被误读成"没关系"）
- 点「查看全部」展开其余

### 3.5 历史宏观环境

近 30 个交易日里，Risk-On / Neutral / Risk-Off **各占几天**。

**用法**：如果今天显示 Risk-Off，而"近 30 日中 Risk-Off 只有 2 天"，说明这是**刚发生的转向**，值得留意；反之若 30 天里 25 天都是它，说明**这已经是常态**，别当成新信号。

⚠️ 数据只支持"近 N 天中 M 天"这种说法，所以页面**不会**写"已持续 X 天"（那是无中生有）。

### 3.6 经济数据（最底下那块，**故意做得比较淡**）

美国 BLS 官方数据四序列：CPI（物价）、PPI（生产端物价）、失业率、非农就业。

- **每个格子都必须显示"数据月份"**（如「数据月份：2026年8月」）——因为经济数据是**月度**发布的，天然滞后于行情。看到"8 月"不要以为没更新，那就是最新一期
- 箭头 ↑/↓ = 该序列的**方向**（同比在升还是在降）
- 底色更浅、边框更弱是**故意的**：这块是「背景资料」，用来解释宏观环境为什么是这样，不需要天天盯

## 4. 中国宏观页（`/macro/cn`）

结构和全球宏观页一样，但讲国内故事。差异点：

| 模块 | 和全球页的不同 |
|---|---|
| 当前宏观环境 | 大字**不是** Risk-On/Risk-Off，而是**四象限中文名**（再通胀/复苏/滞胀/通缩衰退）；旁边的数字是 **PMI 3M**（制造业景气度，**50 是荣枯线**，>50 扩张） |
| 通胀轴 / 增长轴 | 通胀轴 = CPI 同比方向（PPI 二次确认）；**增长轴 = PMI 与 50 比较（水平口径，不是同比方向）** |
| 核心宏观变量 | CPI / PPI / PMI / GDP / M2 / 新增信贷 / 社零 / 失业率 |
| **同比 vs 箭头**（最易误读） | **颜色和正负号 = 同比本身**（本期 vs 去年同月）；**箭头 = 同比较上期是升还是降**。所以会出现「+21.20% ↓」这种组合——**意思是"同比仍正增长，但增速回落"，两句都对**，不是 bug |
| 利率与流动性 | LPR / SHIBOR / 10Y 国债 / 社融。这里的 **Δ 是与 6 个月前相比的 bp 变化**（1bp = 0.01 个百分点），不用同比% —— 因为国债收益率本身就在 2% 附近，算同比没意义 |
| 地产 | **只有北京、上海两个城市**（数据源覆盖所限，非全国口径，页面会标注） |
| 经济数据 | 13 个国内序列（AkShare），同样必须显示数据月份 |

## 5. 名词速查

| 术语 | 一句话解释 |
|---|---|
| **VIX** | 标普 500 的"恐慌指数"：期权市场预期的未来波动。**<20 平静，20~30 警惕，≥30 恐慌** |
| **VXN** | 纳斯达克版的 VIX |
| **MOVE** | 美债版的 VIX（债市波动率）。**<100 平静，100~130 警惕，≥130 恐慌** |
| **10Y 美债 / ^TNX** | 美国 10 年期国债收益率。它是全球资产定价的"锚"，**涨 = 借钱变贵 = 通常压股票** |
| **bp（基点）** | 0.01 个百分点。1bp = 0.01%，100bp = 1% |
| **pp（百分点）** | 两个百分比相减的那个"百分比"。4.00% → 4.30% 是 +0.30pp，不是 +30% |
| **Macro Score** | 本项目的四维度合成分，0~100，50 = 中性 |
| **Risk-On / Risk-Off** | 风险偏好上行 / 避险 |
| **同比增长（YoY）** | 本期 vs 去年同月 |
| **相关系数 r** | -1 ~ +1。+1 = 完全同向，-1 = 完全反向，0 = 无关。**|r| ≥ 0.5 才叫"明显联动"** |
| **回看窗口 n** | 算相关系数用了多少个交易日 |
| **快照 / 数据日** | 这份数字对应的市场日期。**页面所有对比都要先确认双方是同一个数据日** |

## 6. 常见困惑 FAQ

**Q：顶部显示 17.71，告警里写 15.84，是数据错了吗？**
不是。告警是**历史档案**（冻结在触发那天），顶部是**最新收盘**。见 §1①。

**Q：告警阈值为什么是 ±8.4 % 这种奇怪数字？**
动态阈值 = 近 20 个交易日波动率均值 + 2×标准差。市场越平静，阈值越紧。见 §2.4。

**Q：为什么有些卡片写「数据未接入」，有些写「数据暂缺」？**
前者是**设计上没有数据源**（全球市场动态、资金流向）；后者是**有源但这次没取到**（可点重试）。见 §1③。

**Q：页面上的数是实时的吗？**
不是。每天 4 次自动跑时更新。想看最新就点右上角的刷新按钮（它重新拉一次接口，但数据本身还是最新一次运行生成的）。

**Q：Macro Score 从 52 掉到 48，意味着什么？**
意味着四项里至少一项翻转了方向。**看右侧四个因子哪一项变了** —— Score 是结论，因子才是原因。而且 37.5 / 62.5 是分档线，落在这两者之间都属于中性，不用一惊一乍。

**Q：为什么两个页面的「数据截至」日期不一样？**
不同模块**独立取数**，各自可能回看到不同的最近日期（尤其 A股 / 美股板块、以及月度经济数据）。页面会如实标注，看到标注就按标注理解。

**Q：那些灰色闪动的条要等多久？**
正常几秒。**宏观页有 15 秒硬超时**——超时会撤掉骨架、切到失败条 + 重试按钮。首页没有硬超时，取数失败时同样会出现失败条 + 重试（并且**保留上一次的旧图**，所以断网时你还能看旧数据）。

**Q：这个看板能告诉我该买什么吗？**
不能，也不打算能。它做的是**把市场状态客观地摆出来**（异动、环境、相关性、氛围），决定权在你。所有"影响资产""建议"都是固定话术映射，不是推荐。
