# MarketPulse 前端优化实施计划（范围 C：清理 + 去重 + JS 抽离）

## 目标
在**不改变任何视觉与交互行为**的前提下：修复 3 个真实小 bug、清除约 100 行死代码、合并重复定义、统一图表配色来源（CSS 变量单一事实源）、把约 1000 行内联 JS 抽成独立 `web/static/app.js`、对齐 railpack.json 启动命令。不引入新依赖，不触碰 `web/app.py`、`src/*`、`data/*`。

## 涉及文件
- `web/static/app.js`（**新建**，承接内联 JS）
- `web/templates/index.html`（瘦身：删内联脚本、修结构、内联样式改 class）
- `web/static/style.css`（删死规则/去重/新增图表色 token）
- `railpack.json`（startCommand 对齐 `uvicorn web.app:app`）
- `tasks/2026-09-05-frontend-optimize/plan.md`、`journal.md`（按 AGENTS.md 工作规则新建）

## 实施步骤

**第 0 步**：将本计划存入 `tasks/2026-09-05-frontend-optimize/plan.md`。

**第 1 步 — JS 抽离（纯机械搬运，先做，后续改动都在 .js 上做）**
- `index.html:144-1150` 的 `<script>` 内容原样搬到 `web/static/app.js`；head 里的 FOUC 主题预置脚本（L10-18）和 CDN 图表库引用**保留在模板内**（必须早于 CSS 绘制执行）。
- `index.html` 末尾改为 `<script src="/static/app.js"></script>`，位置保持在 body 末尾（执行时机与现在一致）；顺手把游离的 `.shell` 闭合 `</div>`（L1151）归位到 `</main>` 之后。
- `/static` 已挂载，`app.py` 零改动。

**第 2 步 — A 级修复（在 app.js 中）**
1. `sparkColor`：`--muted` → `--text-muted`（修 KPI sparkline 中性色取不到变量的问题）。
2. `renderSector` / `renderAlerts`：所有插值字段补 `escapeHtml`（板块名/领涨股来自 AkShare 外部源）。
3. 删除从未被调用的 `renderBarChart`（约 56 行，GROUPS 全为 line）及 `renderLineChart` 里未使用的 `const ctx`。
4. 内联样式转 class：`#watchlist-section` 的 `display:none` 改 `.hidden` 类（JS 同步改为 classList 切换，共 3 处）；`#chart-watchlist` 的 `height:220px!important` 移入 style.css。

**第 3 步 — B 级去重（在 app.js 中）**
1. 抽公共构建器，`renderLineChart` / `renderWatchChart` 变薄壳：`buildTradingAxis(dates, series)`（交易日轴 + dateIndexMap）、`buildLinePts(series, dates, dateIndexMap)`（前向填充）、`buildLineDataset(s, color)`、`buildLineOptions()`（含 zoom 门控）。预期消除约 130 行重复。
2. 颜色单一来源：style.css 新增 10 个序列色 token（`--c-gspc` 等，Light/Dark 两套，取值 = 现 `COLORS_LIGHT/DARK` 的 hex）+ 7 个图表 UI token（tooltip/axis/grid）；JS 用 `cssVar(name, fallback)` 读取（带 fallback 保底）。删 `COLORS_LIGHT/DARK`，柱图硬编码 hex 改读 `--green/--red`。主题切换重渲染机制已有（pitfall #48 不受影响）。

**第 4 步 — style.css 清理**
- 删死规则：`.theme-toggle`、`.status-dot`/`.dot-*`、`td.st`、`.row-dim`、`.col-status`、`.container`（两处）、`--fs-num`、`--purple`。
- 去重：`.topbar-right`（L136）、`.icon-btn:hover`（L147）、`.lede-accent/pos/neg` 重复段（L233-235）、旧 `:focus-visible` 1px（L49）。
- 解决 `.lede-val` 冲突：**保留现生效的 16px !important + ellipsis**，删无效的 22px（L508）；若你实际想要 22px 再说一声。

**第 5 步 — railpack.json**：`startCommand` 改为 `uvicorn web.app:app --host 0.0.0.0 --port $PORT`（与 Procfile/railway.toml 一致；根 app.py 转发入口不动）。

**第 6 步 — 收尾**：`git diff` 核对改动范围；写 `journal.md`。
